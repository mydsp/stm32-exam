## 3. 构建与烧录

```powershell
cmake --preset <preset>          # 配置（各工程预设见其 README）
cmake --build --preset <preset>  # 编译
pyocd list                       # 确认探针与目标板对应关系
pyocd flash -t <target> <bin>    # 烧录
```

多板项目烧录前需确认探针接在哪块板上：同一条无线 DAP 换板后 Unique ID 不变，
可靠做法是读芯片 ID——`pyocd cmd -t <target> -c "read32 0xE0042000"`，
DEV_ID 低 12 位 F103C8 为 `0x410`、F401RE 为 `0x433`。

## 4. 换机复现

各工程 `CMakeLists.txt` 的 `FW_DIR` 指向本机 Cube 固件包路径，已改为 `CACHE PATH`，
换机时在命令行传 `-DFW_DIR=<路径>` 覆盖即可，无需改文件。工具链文件使用前缀式
`arm-none-eabi-*` 并依赖 PATH，把 `STM32CubeCLT\GNU-tools-for-STM32\bin` 加入 PATH 即可。
构建产物（`build/`、`*.map` 等）已通过 `.gitignore` 排除，仓库中只有源码、文档与演示素材。
